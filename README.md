# Calendar WebUI — Task Management Interface

Современный фронтенд для управления задачами с интерактивным календарем, тегами, приоритетами и встроенной консолью SQL-запросов.

---

## 🚀 Новые возможности

### 2. Панель плавающих кнопок и автоматическая синхронизация
- **Оптимизированный порядок кнопок (сверху вниз):**
  1. 🏠 **«Перейти к сегодняшнему дню»** (`.today-btn-fixed`) — первая кнопка для быстрой навигации к сегодняшней дате.
  2. 🗄️ **«SQL-запрос задач»** (`.sql-btn-fixed`) — открытие интерактивной SQL-консоли.
  3. 🔄 **«Обновить список задач»** (`.sync-btn`) — ручной запуск актуализации данных.
- **Удаление устаревших артефактов файловой БД:**
  - Полностью удалены кнопки ручной выгрузки/загрузки базы (`Upload` / `Download`) и сопутствующие диалоги;
  - Убраны навязчивые тосты о необходимости синхронизировать файлы базы данных и предупреждения `beforeunload`, так как все изменения сохраняются в централизованной СУБД в реальном времени.
- **Автоматическая фоновая синхронизация:**
  - Реализован периодический тихий опрос сервера каждые 20 секунд: новые и измененные задачи синхронизируются в фоне без мерцания интерфейса и сброса скролла.
- **Горячие клавиши:**
  - <kbd>Ctrl</kbd> + <kbd>Enter</kbd> (или <kbd>Cmd</kbd> + <kbd>Enter</kbd>) — мгновенный запуск запроса.
  - <kbd>Esc</kbd> — закрытие модального окна.
- **Быстрые шаблоны (пресеты):**
  - *Все активные задачи* (`SELECT * FROM task WHERE task_status = 1 ORDER BY due_date ASC`)
  - *Задачи с приоритетами* (`SELECT t.task_id, t.title, t.due_date, p.priority_name, p.priority_color FROM task t LEFT JOIN task_priority p ON t.task_priority_id = p.priority_id`)
  - *Задачи по тегам* (`SELECT t.task_id, t.title, tg.tag_text, tg.tag_color FROM task t JOIN task_tag_x_task xt ON t.task_id = xt.task_id JOIN task_tag tg ON xt.task_tag_id = tg.task_tag_id`)
  - *Просроченные задачи* (`SELECT task_id, title, due_date FROM task WHERE task_status = 1 AND due_date < CURRENT_DATE`)
- **Справка по схеме базы данных:**
  - Интерактивный справочник таблиц (`task`, `task_priority`, `task_tag`, `task_tag_x_task`, `task_comment`, `task_status`).
  - Клик по названию таблицы или колонки автоматически вставляет её имя в позицию курсора редактора.
- **Интерактивные результаты:**
  - Динамическая таблица результатов с индикатором общего количества найденных записей.
  - Если в выборке присутствует поле `task_id`, строка становится кликабельной и подсвечивается при наведении; клик по строке открывает полноценное модальное окно задачи для просмотра и редактирования.
  - Специальное визуальное оформление: превью HEX-цветов, отображение `NULL` значений и булевых полей.
  - Кнопка **«Копировать JSON»** для копирования структуры в буфер обмена.
  - Кнопка **«Экспорт в CSV»** с кодировкой UTF-8 BOM для корректного открытия в Excel.
- **Безопасность и валидация:**
  - Валидация запросов на стороне клиента (разрешены только `SELECT`-запросы для чтения).
  - Наглядное отображение ошибок бэкенда (400 Bad Request с текстом ошибки из `detail`).

## 🛠 Архитектурные улучшения UI/UX

### Надежный расчет скролла в CalendarStrip
- Устранен хардкодный расчет смещения `LOAD_MORE_DAYS*(30/95)`.
- Реализовано точное измерение смещения через DOM: до вставки новых карточек фиксируется экранное положение карточки-якоря через `getBoundingClientRect().left`. В `useLayoutEffect` вычисляется реальный сдвиг и компенсируется скролл контейнера (с резервным расчетом через дельту `scrollWidth`).
- Исправлен порядок добавления будущих дат при прокрутке вправо.

### Умные Toast-уведомления
- Реализовано автоматическое закрытие тостов по таймеру (3.5 секунды), чтобы всплывающие уведомления не перекрывали интерфейс.
- Добавлена кнопка ручного закрытия (`X`) на каждом тосте.
- Долгие фоновые процессы (синхронизация с облаком, загрузка праздников) не закрываются по таймеру до фактического завершения операции.

### Доступность и темы оформления
- Поддержка закрытия модальных окон по нажатию клавиши <kbd>Escape</kbd>.
- Полная адаптация стилей под светлую и темную темы (переменные `--bg-modal`, `--bg-element`, `--border-color`, `--text-primary`).
- Аккуратные плавные тени, оптимизированные скроллбары таблицы и читаемые моноширинные шрифты.
